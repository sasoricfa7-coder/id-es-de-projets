La Licence Publique Générale GNU Affero est une licence libre et
copyleft pour les logiciels et autres types d'œuvres, spécialement
conçue pour garantir la coopération avec la communauté dans le cas
des logiciels de serveurs en réseau.

Les licences de la plupart des logiciels et autres œuvres pratiques
sont conçues pour vous priver de la liberté de partager et de
modifier ces œuvres. À l'inverse, nos Licences Publiques Générales
ont pour but de garantir votre liberté de partager et de modifier
toutes les versions d'un programme — afin de s'assurer qu'il reste
un logiciel libre pour tous ses utilisateurs.

Quand nous parlons de logiciel libre, nous parlons de liberté, pas
de prix. Nos Licences Publiques Générales sont conçues pour vous
garantir la liberté de distribuer des copies de logiciels libres (et
de les facturer si vous le souhaitez), de recevoir le code source ou
de pouvoir l'obtenir si vous le voulez, de pouvoir modifier le
logiciel ou en utiliser des parties dans de nouveaux programmes
libres, et de savoir que vous pouvez faire tout cela.

Les développeurs qui utilisent nos Licences Publiques Générales
protègent vos droits en deux étapes : (1) ils affirment un droit
d'auteur sur le logiciel, et (2) ils vous offrent cette licence, qui
vous donne la permission légale de copier, distribuer et/ou modifier
le logiciel.

Un avantage secondaire de la défense de la liberté de tous les
utilisateurs est que les améliorations apportées dans des versions
alternatives du programme, si elles connaissent une large diffusion,
deviennent disponibles pour que d'autres développeurs puissent les
intégrer. De nombreux développeurs de logiciels libres sont
encouragés par la coopération qui en résulte. Cependant, dans le cas
des logiciels utilisés sur des serveurs en réseau, ce résultat peut
ne pas se produire. La Licence Publique Générale GNU permet de créer
une version modifiée et de la rendre accessible au public sur un
serveur sans jamais rendre publique le code source correspondant.

La Licence Publique Générale GNU Affero est spécifiquement conçue
pour garantir que, dans de tels cas, le code source modifié devienne
accessible à la communauté. Elle exige de l'exploitant d'un serveur
en réseau qu'il fournisse le code source de la version modifiée qui
y fonctionne aux utilisateurs de ce serveur. Ainsi, l'utilisation
publique d'une version modifiée, sur un serveur accessible au
public, donne au public accès au code source de cette version
modifiée.
